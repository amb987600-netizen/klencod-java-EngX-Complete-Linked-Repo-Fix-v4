# التحقق من حزمة EngX للمستودع المرتبط

## ما نجح

- تثبيت تبعيات الواجهة من `package-lock.json` باستخدام `npm ci`.
- اختبارات الواجهة والمنطق وworkflow: **93 اختبارًا ناجحًا في 20 ملفًا** باستخدام `npm test`، وأعيد تشغيلها بعد التعديلات.
- `npm run android:sync`: فحص TypeScript وبناء Vite ثم مزامنة Capacitor مع Android، مع اكتشاف الإضافات الخمس.
- تثبيت تبعيات الخادم من ملف القفل واختباراته: **20 اختبارًا ناجحًا** باستخدام `npm test` داخل `server/`.
- أداة استبدال ملفات المستودع: **5 اختبارات Python ناجحة** باستخدام `python3 tests/repo-replacement.test.py`. تشمل معاينة دون كتابة، الحفاظ على `.git` و`.env` والملفات غير المرتبطة، نسخ workflows أندرويد القديمة احتياطيًا وتعطيلها، وتجنب المسارات المتداخلة والروابط الرمزية.
- قراءة YAML والتحقق من صياغة Bash، ومن حزم SDK المطلوبة ومسار Gradle. جرى تنفيذ خطوة اكتشاف جذر التطبيق على ملفات اختبار للمصدر في الجذر وداخل `EngX/`. هذا فحص محلي وليس تشغيلًا على GitHub.
- المقارنة بالمصدر الأصلي: كل ملفات الحزمة الأصلية محفوظة، وكود `src/` والخادم وiOS وإضافات Java/Kotlin وموارد Android لم يتغير. التعديلات تخص workflow وتعليمات الرفع والاختبارات وأداة التحديث وملف تجاهل النسخ الاحتياطية.

## ما لم يُختبر

لم يُشغّل workflow على مستودعك أو داخل Klencod، ولم يُبنَ APK ناجح أو يُختبر هاتف فعلي. فحص `android:doctor` في هذه البيئة اكتشف غياب Android SDK platform 35 وbuild-tools 35.0.0، فلم يبدأ بناءً. Java 21 متاحة محليًا لكن مترجم `javac` غير متوفر؛ المحاولة المحلية للمراجعة توقفت لغياب `JAVA_COMPILER`. هذه قيود البيئة وليست إثباتًا لنجاح أو فشل التجميع في GitHub بعد تثبيت الأدوات.

ملف GitHub يجهز JDK 21 وSDK المطلوبين، لكن تبقى مرحلة تجميع الاعتمادات الأصلية والتشغيل على الجهاز بحاجة لاختبار فعلي. تحذيرات تقسيم حزم Vite لا تمنع نجاح بناء الويب. الحزمة لا تحتوي APK أو مفاتيح توقيع شخصية؛ الناتج المتوقع عند نجاح workflow هو APK debug للاختبار فقط.

## فحص الملف المضغوط

تحتوي الحزمة على `SOURCE-MANIFEST.sha256` ببصمة SHA-256 لكل ملف، باستثناء ملف البصمات نفسه. فحص التسليم يتحقق من CRC للأرشيف ومن مطابقة كل ملف لبصمته ومن عدم نقص أي ملف أصلي. يمكن إعادة فحص البصمات من مجلد الحزمة على Linux/macOS باستخدام:

```bash
sha256sum -c SOURCE-MANIFEST.sha256
```

اتبع [تعليمات تحديث المستودع](../REPLACE-LINKED-REPO.ar.md)؛ المهم إزالة workflow أندرويد القديم وتسجيل التغيير، وليس رفع ZIP كملف واحد أو إعادة تشغيل محاولة قديمة.
